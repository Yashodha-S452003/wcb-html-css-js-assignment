# WCB HTML/CSS/JavaScript Assignment

This repository recreates the two supplied WCB documents using HTML, CSS and JavaScript.

## Exercises

### Exercise 1 – Worker Progress Report
- 3-page layout
- WCB header/logo
- Claim number, worker name, app ID and submission time
- Dynamic return-to-work selections
- Dynamic recovery and medical-treatment fields
- Dynamic pain rating
- Dynamic medication/home-exercise selections
- Page numbers and footer
- Two datasets for browser demonstration
- Print / Save as PDF

### Exercise 2 – Medical & Travel Expense Request
- 2-page layout
- WCB header/logo
- Claim number and worker information
- Dynamic tables for:
  - Prescription Drugs
  - Over-the-Counter Drugs
  - Medical Supplies
  - Parking
  - Mileage
  - Bus/Taxi fares
- Multiple datasets
- Add Prescription Row demonstration
- Page numbers and footer
- Print / Save as PDF

## How to run

No build tools are required.

Open:
- `exercise-1/index.html`
- `exercise-2/index.html`

The pages use only HTML, CSS and JavaScript.

## Dynamic demonstration

Use the Demo 1 and Demo 2 buttons to switch between different data sets.

For Exercise 2, use **Add Prescription Row** to demonstrate that table rows are generated dynamically.

## Video submission

Place the two narrated PiP videos in the `videos/` directory or replace the placeholder files with your final recordings.

Suggested names:
- `exercise-1-demo.mp4`
- `exercise-2-demo.mp4`

Each video should be approximately 2 minutes and cover:
1. Requirement understanding and assumptions
2. Browser demonstration with different datasets
3. Code walkthrough
4. Challenges and solutions
5. AI usage and prompt history
